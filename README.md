- **Student Mode**: 100% English UI, student identity card, reasoning textareas, font controls (`A-`, `Default`, `A+`, `Font: Sans-Serif`), class discussion performance summary (without right/wrong status badges).
- **Vocabulary Lab**: 90 academic vocabulary words across 6 texts (15 words per text) with TTS audio pronunciation, flipcards, and matching games.
- **TKA Strategy Guide**: 9 core exam formulas and step-by-step methodologies.
